# End User Interview

**Teacher**

1. What is the main goal of this screen from your perspective?
2. Is the current layout aligned with the way you expect students or teachers to work?
3. Are there any steps you expected to see here but don’t?
4. Is it clear how to create or schedule a workshop from these screens?

**User Management**

1. Is the information shown for each student helpful?
2. Do teachers need additional filtering options?

**Student-Focused Questions
Assignments & Workshops**

1. Is it clear for students how to submit a help request?
2. Do you think younger students (8–12) can understand this navigation easily?
3. Do students need to see deadlines? Or should everything be based on meetings?

**Interaction & Usability**

1. Is the navigation intuitive, or do you expect users to get stuck anywhere?
2. Are there screens with too much information, or too little?
3. Do you see any unnecessary steps in the user flow?

**Functional & Technical Expectations**

1. Are there any privacy/safety concerns regarding student data shown on screen?
2. Are there specific external tools we need to integrate with (Google Classroom, GitHub,
scratch, etc.)?

**Validation**

1. Do these screens correctly reflect the user flows we previously defined?
2. Are there features you expected to see at this stage but haven’t yet?
3. Is there anything in the wireframes that doesn't match your teaching reality?
4. If you had to use this screen tomorrow, what would still worry you?
